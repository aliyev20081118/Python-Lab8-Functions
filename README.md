## 📂 Qovluğun Strukturu
- `utils.py` - Köməkçi funksiyaların (Tapşırıq 2, 3, 5, 6) saxlanıldığı ayrıca modul.
- `lab8_main.py` - Əsas icra faylı. `while` dövrü və modulların import edilməsi (Tapşırıq 1, 4, 5, 6, 7) bu faylda yerləşir.
- `task8_fixed.py` - Əvvəlcədən daxilində 4 xəta olan, lakin sonradan tapılıb düzəldilmiş (debug olunmuş) kod faylı (Tapşırıq 8).
- `Hesabat_Lab8.docx` - Hissə A üçün proqnoz və izahlar, həmçinin nəzəri sualların cavabları və xəta cədvəlinin olduğu yekun hesabat faylı.
